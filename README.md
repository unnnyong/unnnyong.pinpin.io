# Pinpin website

`https://unnnyong.pinpin.io`에 공개할 Pinpin 소개 사이트입니다.

## GitHub Pages 설정

GitHub 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/(root)`로 설정합니다.

`app-ads.txt`는 현재 비어 있습니다. 공개 후 AdMob에서 안내하는 다음 형식의 레코드로 채우세요.

```text
google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
```

커스텀 도메인의 DNS에는 GitHub Pages 저장소가 안내하는 레코드를 설정하고, Pages 설정에서 `unnnyong.pinpin.io`를 확인하세요.

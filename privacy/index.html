01 · SUPPORT

자주 묻는 질문

어떤 Instagram 링크를 사용할 수 있나요?

Instagram 게시물과 릴스 링크를 사용할 수 있습니다. 비공개 계정의 게시물, 삭제된 게시물, 로그인이나 연령 확인이 필요한 게시물, Instagram이 접근을 제한한 게시물은 분석하지 못할 수 있습니다.

링크를 넣었는데 장소를 찾지 못해요.

핀핀은 게시물의 공개 메타데이터, 본문, 위치 태그, 썸네일에서 장소 단서를 찾습니다. Instagram이 이 정보를 제공하지 않거나 장소명이 이미지에만 있는 경우에는 분석이 실패할 수 있습니다. 장소명이나 주소가 보이는 스크린샷을 선택해 다시 분석해 보세요.

사진 전체에 접근하나요?

아니요. 핀핀은 iOS 사진 선택기를 통해 사용자가 직접 고른 이미지만 불러옵니다. 선택한 이미지의 문자 인식은 Apple Vision 프레임워크로 기기 내에서 처리됩니다.

선택한 스크린샷이 외부로 전송되나요?

스크린샷 이미지 원본은 OpenAI로 전송하지 않습니다. 다만 기기에서 인식한 OCR 텍스트는 Instagram 링크 및 공개 게시물 정보와 함께 OpenAI API로 전송되어 장소명과 지도 검색어를 추출하는 데 사용됩니다. 민감한 정보가 포함된 스크린샷은 선택하지 마세요.

분석된 장소가 정확하지 않아요.

자동 분석 결과는 원본 게시물의 표현과 외부 서비스의 응답에 따라 부정확할 수 있습니다. 저장하기 전에 장소명, 주소, 국가, 카테고리를 확인하고, 제공되는 지도 링크로 실제 장소가 맞는지 검토해 주세요.

어떤 지도로 열리나요?

국내 장소는 네이버지도와 카카오맵에서, 해외 장소는 Google 지도에서 확인할 수 있습니다. 해당 지도 앱이 없거나 앱 링크를 열 수 없으면 웹 페이지로 열릴 수 있습니다.

저장한 장소와 메모는 어디에 보관되나요?

저장한 Instagram 원본 링크, 공개 게시물에서 추출한 텍스트, 썸네일, 장소 정보, 즐겨찾기, 메모는 기본적으로 사용자의 기기 내부에 저장됩니다. 현재 핀핀은 계정 가입, 핀핀 서버 동기화, 기기 간 자동 백업을 제공하지 않습니다.

앱을 삭제하면 데이터도 삭제되나요?

앱 내부에 저장된 장소, 메모, 즐겨찾기, 원본 게시물 정보는 앱을 삭제할 때 함께 삭제됩니다. 앱을 삭제하기 전에 필요한 정보를 따로 확인해 주세요. 이용 통계나 광고 제공 과정에서 외부 서비스가 이미 처리한 정보는 각 제공자의 보관 기준에 따릅니다.

클립보드는 언제 읽나요?

핀핀은 클립보드에 Instagram 링크로 보이는 내용이 있는지 iOS의 패턴 탐지 기능으로 확인해 가져오기 제안을 표시할 수 있습니다. 사용자가 붙여넣기 또는 제안을 통한 가져오기를 실행하면 링크 문자열을 읽어 분석에 사용합니다.

오류를 제보할 때 무엇을 보내야 하나요?

사용 중인 기기와 iOS 버전, 핀핀 앱 버전, 문제가 발생한 단계, 화면에 표시된 오류 문구를 함께 보내주세요. Instagram 링크나 스크린샷에 개인정보가 포함되어 있다면 필요한 부분만 남기고 가려서 보내세요.

2.2. 장소 분석을 위한 OpenAI API 이용

핀핀은 장소명과 지도 검색어를 추출하기 위해 OpenAI Responses API를 이용합니다. 분석 시점에 다음 정보가 암호화된 통신을 통해 OpenAI로 전송됩니다.

  • Instagram 게시물 URL
  • Instagram 공개 페이지에서 가져온 본문·메타데이터·위치 태그 등의 텍스트
  • 게시물 썸네일과 사용자가 선택한 스크린샷에서 기기 내 OCR로 인식한 텍스트

스크린샷 이미지 원본과 썸네일 이미지 원본은 OpenAI API에 전송하지 않습니다. API 요청은 응답을 장기 저장하지 않도록 store: false로 전송됩니다. 다만 OpenAI는 서비스 안전과 오남용 방지를 위한 로그를 기본적으로 최대 30일간 보관할 수 있으며, 법령상 의무 등에 따라 더 오래 보관할 수 있습니다. OpenAI API로 전송된 데이터는 OpenAI가 명시적 동의 없이 모델 훈련에 사용하지 않는다는 API 데이터 정책의 적용을 받습니다.

OpenAI API 데이터 컨트롤에서 자세한 내용을 확인할 수 있습니다.

2.3. 기기 내 저장과 보관 기간

다음 정보는 SwiftData를 이용해 기본적으로 사용자의 기기 내부에 저장됩니다.

  • Instagram 원본·정규화 URL, shortcode, 게시물 유형
  • Instagram 공개 페이지에서 추출한 텍스트와 OCR 텍스트
  • 게시물 썸네일
  • 저장한 장소 정보, 즐겨찾기, 메모

이 정보는 사용자가 해당 장소를 삭제하거나 앱을 삭제할 때까지 보관될 수 있습니다. 한 게시물에서 저장한 마지막 장소를 삭제하면 연결된 원본 게시물 정보도 함께 삭제됩니다. 사용자가 iOS 백업 설정을 사용하는 경우에는 Apple의 백업 정책과 사용자 설정에 따라 앱 데이터가 다루어질 수 있습니다.

고객 문의 내용은 문의 처리와 분쟁 대응에 필요한 기간 동안 보관한 뒤 삭제합니다. 다만 관계 법령에서 별도의 보관 의무를 정한 경우에는 해당 기간 동안 보관할 수 있습니다.

2.5. 광고 식별자와 추적

핀핀은 App Tracking Transparency(ATT) 권한을 요청하지 않으며, 코드에서 IDFA를 직접 수집하거나 사용하지 않습니다. 또한 Firebase Analytics 이벤트에 사용자가 입력한 콘텐츠를 전송하지 않습니다.

다만 핀핀은 Google AdMob 배너 광고를 제공하며, Google Mobile Ads SDK는 적용 법령, 사용자의 지역과 동의 상태, Google의 설정에 따라 광고 제공·빈도 제어·측정·부정 이용 방지를 위한 정보를 처리할 수 있습니다. ATT 허용이 없어 IDFA가 제공되지 않더라도 IP 주소, 기기 정보, 앱 인스턴스 또는 발행자 제1자 식별자, 광고 상호작용 정보 등이 처리될 수 있습니다.

2.6. 앱 권한과 기기 기능

  • 사진: 사용자가 직접 선택한 스크린샷에서 장소 텍스트를 인식하기 위해 사용합니다. 사진 보관함 전체를 자유롭게 탐색하는 방식이 아니라 iOS 사진 선택기를 이용합니다.
  • 클립보드: Instagram URL을 빠르게 입력하기 위해 사용합니다. iOS의 패턴 탐지 기능으로 URL 가능성을 확인하고, 사용자가 붙여넣기 또는 가져오기를 실행할 때 링크를 사용합니다.
  • 카메라·마이크·알림·위치: 현재 핀핀은 이 권한을 요청하지 않습니다.

2.7. 사용자의 권리와 삭제 방법

사용자는 장소 상세 화면에서 저장한 장소와 연결된 메모·즐겨찾기 정보를 삭제할 수 있습니다. 기기에 저장된 핀핀 데이터 전체를 삭제하려면 앱을 삭제할 수 있습니다.

개인정보 처리, 열람·정정·삭제, 처리 정지, 분석·광고 정보와 관련한 문의는 unnnyong@icloud.com으로 접수할 수 있습니다. 외부 서비스가 보유한 정보의 삭제는 해당 제공자의 정책과 식별 가능 여부에 따라 제한될 수 있습니다.

사용자는 Instagram 링크나 스크린샷을 제공하지 않음으로써 AI 장소 분석을 위한 정보 전송을 거부할 수 있습니다. 이 경우 장소 가져오기 기능은 이용할 수 없지만, 이미 저장된 장소를 보는 기기 내 기능은 계속 이용할 수 있습니다.
